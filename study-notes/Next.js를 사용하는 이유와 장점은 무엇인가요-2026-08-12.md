# Next.js를 사용하는 이유와 장점은 무엇인가요?

- 검색 엔진 최적화가 중요하거나, 초기 로딩 성능이 중요할 때, 복잡한 데이터 페칭 전략이 필요하거나, 프런트엔드와 백엔드 로직을 하나의 프로젝트 내에서 통합하고 싶은 경우에 Next.js는 리액트를 단독으로 사용할 때보다 훨씬 강력하고 효율적인 선택지가 된다.

> 리액트는 UI 구축에는 강력하지만 SEO, 초기 로딩, 라우팅, API 관리, 이미지 최적화 같은 프로덕션 기능은 부족합니다. Next.js는 SSR/SSG/ISR, 파일 기반 라우팅, API Routes, 이미지 최적화 등으로 이러한 한계를 해결하고 성능과 생산성을 높입니다. 따라서 Next.js는 대규모 웹 앱에서 리액트를 보완하는 필수적인 풀스택 프레임워크입니다.

1. 리액트의 한계
	1. UI 렌더링에만 집중하는 라이브러리이므로 실제 프로덕션 수준의 웹 앱을 구축하는데 필요한 모든 기능을 제공하지는 않음
	2. 주로 CSR 방식으로 동작하여 검색 엔진 최적화에 불리하고 초기 로딩 성능과 사용자 경험이 저하될 수 있음
	3. 라우팅, API 연동, 이미지 최적화와 같은 기능을 직접 구현하거나 별도 라이브러리에 의존해야하기에 구조와 설정이 복잡함
2. Next.js 란?
	1. 리액트의 한계를 보완하기 위해 등장한 리액트 기반의 풀스택 웹 프레임워크
	2. Vercel에서 출시함
	3. Next.js는 검색 엔진 최적화, 초기 로딩 성능, 라우팅 등 실제 서비스 운영에 필요한 요소를 프레임워크 차원에서 해결하여 개발자가 비즈니스 로직에만 집중할 수 있도록 도움

## Next.js를 사용하는 이유

- Next.js는 리액트를 단독으로 사용할 때 발생하는 한계를 해결하고 생산성과 앱 성능을 향상시키는 다양한 기능을 제공

### SSR, SSG

1. Next.js는 페이지 단위로 렌더링 방식을 선택할 수 있다.
2. SSR
	1. 서버에서 완성된 HTML을 생성하여 전송하므로 검색 엔진 크롤러가 콘텐츠를 쉽게 수집 가능
	2. 사용자는 빈 화면 없이 빠르게 웹 사이트를 확인 가능
3. SSG
	1. 빌드 시점에 HTML을 미리 생성해 배포
	2. 가장 빠른 로딩 속도와 뛰어난 검색 엔진 최적화 성능을 제공
4. ISR
	1. 정적 페이지를 주기적으로 갱신

### 파일 시스템 기반 라우팅

1. Next.js는 파일 시스템 기반 라우팅을 제공하여 별도의 라우팅 라이브러리를 사용할 때보다 간단하게 라우트를 구성할 수 있다.
2. 파일 구조 자체가 URL 구조가 되어서 직관적으로 관리 가능
3. next/link 컴포넌트는 화면에 보이는 링크를 자동으로 프리페칭하기 때문에 페이지 전환 속도가 매우 빠름

### API Routes

1. 별도의 백엔드 서버를 구축하지 않고도 서버 쪽 로직을 함께 구현할 수 있는 기능
2. 이를 통해 CORS 설정의 복잡함을 줄일 수 있고 민감함 API 키가 외부에 노출될 위험도 막을 수 있다.
3. pages/api, app/api 디렉터리 안에 자바스크립트 파일을 생성하는 것만으로 백엔드 API 엔드포인트를 만들 수 있다.
4. 하나의 프로젝트 안에서 프론트엔드와  백엔드 로직을 함께 관리하는 풀스택 개발이 가능
5. 서버리스 함수로 배포되어 요청이 있을 때만 실행되므로 비용 효율적이며 클라이언트에서 직접 접근할 수  없는 로직을 서버에서 안전하게 처리할 수 있다는 장점이 있다.

### 이미지 최적화

1. Next.js의 `<Image>` 컴포넌트는 이미지를 자동으로 최적화하여 제공한다.
	1. 사용자의 기기와 뷰포트 크기에 따라 적절한 크기의 이미지를 자동으로 로드하여 불필요한 데이터 전송을 줄이고, 이미지가 뷰포트에 들어올 때까지 불필요한 로딩을 지연해 초기 로딩 성능을 향상시킨다.
2. 이미지를 WebP나 AVIF같은 최신 포맷으로 자동 변환하여 파일 크기를 줄이며 이미지 크기를 미리 계산해 렌더링 하므로 이미지 로딩으로 인한 레이아웃 밀림(CLS) 현상도 방지할 수 있다.

### 기타 생산성과 성능 관련 기능

1. CSS 모듈, 테일윈드 CSS등 다양한 스타일링 방식을 지원하여 프로젝트 성격과 선호에 맞는 방식으로 UI를 구축할 수 있다.
2. 개발 중에는 Fast Refresh 기능을 통해 코드 변경 사항이 화면에 빠르게 업데이트되어 개발 생산성을 높인다.
3. 타입스크립트를 기본적으로 지원한다.
4. 리액트 서버 컴포넌트, 스트리밍, 중첩 레이아웃 등 리액트의 최신 기능을 선도적으로 도입하여 더욱 진화된 웹 개발 패턴을 제공한다.
