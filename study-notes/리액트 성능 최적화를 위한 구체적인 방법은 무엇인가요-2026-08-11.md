# 리액트 성능 최적화를 위한 구체적인 방법은 무엇인가요?


> 리액트 성능 최적화의 핵심은 불필요한 리렌더링 방지와 초기 로딩, 번들 최적화입니다. React.memo, useCallback, useMemo를 활용해 컴포넌트와 함수, 값의 재생성을 최소화하고 코드 스플리팅과 이미지 최적화로 로딩 속도를 개선합니다. 실제 적용은 프로파일링 도구로 병목을 확인한 후 필요한 부분에만 전략적으로 적용하는 것이 중요합니다.

- 리렌더링 같은 불필요한 작업을 줄이고 리소스 로딩을 최적화하는 것이 리액트 성능 최적화의 핵심

# 메모이제이션 기법

1. 문제 지점
	1. 리액트 컴포넌트는 props나 state가 변경될 때마다 리렌더링이 된다.
	2. 하지만 때로는 위 값들이 실제로 의미 있게 변경되지 않았음에도 다시 렌더링하여 성능이 저하될 수 있다.
2. 메모이제이션이란?
	1. 함수의 연산 결과를 저장해 두었다가 같은 입력이 들어오면 다시 계산하지 않고 저장된 값을 재사용하는 기법

## 컴포넌트 메모이제이션 → `React.memo`

1. 고차 컴포넌트로 렌더링 결과가 동일한 컴포넌트를 메모이제이션하여 props가 변경되지 않는 한 리렌더링을 방지
	1. 고차 컴포넌트란? ((HOC, Higher-Order Component)
		1. 컴포넌트를 인자로 받아서, 새로운 컴포넌트를 반환하는 함수

```javascript
import React from 'react';

const ChildComponent = ({ name, age, onClick}) => {
	console.log('ChildComponent 렌더링'); // name이나 age가 변하지 않으면 출력되지 않음
	
	return(
		<div>
			<p>이름: {name}</p>
			<p>나이: {age}</p>
			<button onClick={onClick}>클릭</button>
		</div>
	);
};

export default React.memo(ChildComponent); // React.memo로 감싸기
```


```javascript
import React, {useState} from 'react';
import ChildComponent from './ChildComponent';

function ParentComponent () => {
	const [count, setCount] = useState(0);
	const [use, setUser] = useState({ name: 'Alice', age: 30 });
	
	const handleClick = () => {
		console.log('버튼 클릭됨');
	};
	
	return(
		<div>
			<h1>ParentComponent</h1>
			<p>카운트: {count}</p>
			<button onClick={()=> setCount(count + 1)}>카운트 증가</button>
			{/* user.name과 user.age가 변하지 않는 한 ChildComponent는 리렌더링 되지 않음 */}
			<ChildComponent name={user.name} age={user.age} onClick={handleClick}>
		</div>
	);
};
```

1. React.memo로 감싸진 컴포넌트는 새로운 props가 들어오면 이전 props와 얕은 비교를 수행,
모든 props가 동일하다면 컴포넌트를 다시 렌더링하지 않고 마지막 렌더링 결과를 재사용
2. onClick과 같은 함수 props는 부모 컴포넌트가 리렌더링될 때마다 새로운 함수 인스턴스가 생성되므로, React.memo를 사용하더라도 자식 컴포넌트가 리렌더링될 수 있다.
	1. 이를 해결하기 위해 useCallback을 사용한다.

## 함수 메모이제이션 → `useCallback`

1. 함수형 컴포넌트 내에서 정의된 이벤트 핸들러 등의 콜백 함수를 메모이제이션하여 <u>특정 의존성이 변경되지 않는 한</u> 함수를 다시 생성하지 않도록 한다.
2. useCallback은 처음 렌더링될 때 함수를 생성하고 이후에는 의존성 배열의 값이 변경되지 않았다면 이전에 생성된 함수를 재사용한다.
	1. 새로운 함수 참조가 생성되지 않으므로 이 함수를 props를 받는 React.memo로 감싸진 자식 컴포넌트의 불필요한 리렌더링을 막을 수 있다.

```javascript
import React from 'react';

const ChildComponent = ({ name, age, onClick}) => {
	console.log('ChildComponent 렌더링'); // name이나 age가 변하지 않으면 출력되지 않음
	
	return(
		<div>
			<p>이름: {name}</p>
			<p>나이: {age}</p>
			<button onClick={onClick}>클릭</button>
		</div>
	);
};

export default React.memo(ChildComponetn); // React.memo로 감싸기
```


```javascript
import React, {useState, useCallback} from 'react';
import ChildComponent from './ChildComponent'; // React.memo로 감싸진 자식 컴포넌트

function ParentComponent () => {
	const [count, setCount] = useState(0);
	const [use, setUser] = useState({ name: 'Alice', age: 30 });
	
	const handleClick = useCallback(() => {
		console.log('버튼 클릭됨');
	}, [count]);
	// count가 변경될 때만 이 함수가 새로 생성됨
	
	return(
		<div>
			<h1>ParentComponent</h1>
			<p>카운트: {count}</p>
			<button onClick={()=> setCount(count + 1)}>카운트 증가</button>
			{/* handleClick 함수 참조가 count가 변하기 전까지는 동일하므로,
				ChildComponent는 name/age가 변하지 않는 한 리렌더링 되지 않음 */}
			<ChildComponent name={user.name} age={user.age} onClick={handleClick}>
		</div>
	);
};
```


## 값 메모이제이션 → `useMemo` 

1. 복잡한 계산의 결괏값이나 객체, 배열 등의 참좃값을 메모이제이션하여 특정 의존성이 변경되지 않는 한 값을 다시 계산하거나 새로운 참조를 생성하지 않도록 한다.
2. useMemo는 인자로 전달된 함수가 반환하는 값을 메모리에 저장하고 <u>의존성 배열의 값이 변경될 때만 해당 함수를 다시 실행</u>하여 값을 재계산한다.

```javascript
import React, { useState, useMemo } from 'react';

function CalculateComponent({ num1, num2}) {
	// num1이나 num2가 변경될 때만 expensiveCalculation이 실행되고, 결과가 메모이제이션됨
	
	const calculatedValue = useMemo(() => {
		console.log('복잡한 계산 실행!');
		// 아주 복잡하고 시간이 오래 걸리는 계산...
		return num1 * num2 * 12345678;
	}, [num1, num2]);
	
	return (
		<div>
			<p>값 1: {num1}</p>
			<p>값 2: {num2}</p>
			<p>계산된 값: {calculatedValue}</p>
		</div>
	);
};
```

# 앱 로딩 시간 개선하기

1. 앱의 초기 로딩 시간은 사용자 경험에 큰 영향을 주기에 개선하여 사용자 경험을 높여주는 것이 좋다.

### 코드 스플리팅

1. 코드 스플리팅이란
	1. 앱의 모든 코드를 하나의 큰 번들 파일로 만드는 대신 필요한 시점에 필요한 코드만 로드하도록 번들을 여러 개의 작은 파일로 나누는 기법
2. 처음 로딩할 때 내려받아야 할 자바스크립트 번들 크기를 줄여 페이지 로드 속도가 크게 향상된다.

### 지연 로딩

1. 사용자가 특정 기능을 사용할 때만 해당 코드를 로드하여 불필요한 리소스 낭비를 줄일 수 있다.
2. React.lazy와 Suspense를 사용하면 컴포넌트를 필요할 때 동적으로 컴포넌트를 로드할 수 있다.

```javascript
import React, { Suspense } from 'react';

//MyHeavyComponent는 필요할 때만 로드된다.
const MyHeavyComponent = React.lazy(() => import('./MyHeavyComponent'));

function App() {
	const [showHeavyComponent, setShowHeavyComponent] = React.useState(false);
	
	return (
		<div>
			<button onClick={() => setShowHeavyComponent(true)}>무거운 컴포넌트 보기</button>
			{ShowHeavyComponent && (
				{/* 로딩 중 표시할 UI */}
				<Suspense fallback={<div>로딩중...</div>}
					<MyHeavyCompoenent/>
				</Suspense>
			)}
		</div>
	);
}
```


### 이미지 최적화

1. 웹 페이지의 성능에 가장 큰 영향을 미치는 요소 중 하나가 이미지
2. 개선 방법
	1. **적절한 이미지 형식**
		1. JPEG(사진), PNG(투명 배경), WebP/AVIF(차세대 포맷, 높은 압축률) 사용
	2. **이미지 압축**
		1. 품질 저하 없이 파일 크기를 줄임
	3. **반응형 이미지**
		1. `<picture>` 태그나 srcset 속성을 사용하여 기기 해상도에 맞는 최적의 이미지를 제공
	4. **지연 로딩**
		1. `loading=’lazy’` 속성을 사용하여 이미지가 뷰포트에 들어올 때까지 로딩을 지연시킴
	5. **CDN**
		1. 이미지와 같은 정적 자산을 사용자에게 더 가까운 서버에서 빠르게 전송

### 번들러 최적화

1. 리액트 프로젝트에서 주로 사용되는 웹팩같은 번들러의 설정을 최적화하여 최종 번들 파일의 크기를 줄이고 로딩 성능을 개선
2. 개선 방법
	1. **트리 셰이킹**
		1. 사용되지 않는 코드를 최종 번들에서 제거
	2. **Minification & Uglification**
		1. 코드의 불필요한 공백, 주석 등을 제거하고 변수 이름을 짧게 변경하여 파일 크기를 줄임
	3. **캐싱 전략**
		1. 브라우저 캐싱을 활용하여 재방문 시 빠르게 리소스를 로드
