# `<canvas>` 태그란 무엇인가요?


> `<canvas>` 태그는 HTML 문서 내에서 자바스크립트를 사용해 동적인 그래픽, 도형, 애니메이션을 구현할 수 있는 도화지 역할을 합니다. 비트맵 기반으로 작동하며 모든 시각적 요소는 코드로 직접 그립니다. 그린 후에는 개별 객체가 아닌 캔버스의 일부가 되므로 수정하려면 다시 그려야 합니다.  
> 이 기술을 활용하면 데이터 시각화, 2D게임, 이미지 편집기, 온라인 서명 패드 등 다양한 상호작용형 웹 그래픽과 앱을 만들 수 있습니다.


### <canvas> 태그의 의미와 특징

1. `<canvas>` 태그란?
	1. HTML5에서 추가된 그래픽요소
	2. HTML 문서 안에 그림을 그릴 수 있는 캔버스나 도화지 같은 영역을 만드는 태그
	3. 실제로 그림을 그리고, 도형을 만들고, 애니메이션을 구현하는 작업은 자바스크립트로 이루어짐
2. `<img>`, `<canvas>` 차이
	1. `<img>`
		1. 정적인 이미지를 보여 줌
	2. `<canvas>`
		1. 동적인 그래픽 처리도 가능
3. `<canvas>` 태그의 주요 특징
	1. 자바스크립트 기반 드로잉
		1. 모든 시각적 요소는 자바스크립트의 Canvas API나 WebGL API를 사용해 코드로 직접 그린다.
	2. 비트맵 방식으로 작동
		1. 픽셀 단위를 제어하는 비트맵 방식으로 작동
		2. 한번 그려진 도형은 독립된 객체가 아니라 캔버스라는 전체 그림의 일부 픽셀로 합쳐짐
		3. 수정을 위해서는 해당 부분을 지우고 다시 그려야 함
	3. 다양한 활용성
		1. 단순 도형, 그래프, 복잡한 게임, 데이터 시각화, 사진 편집기, 실시간 영상 처리까지 무궁무진하게 활용 가능

### `<canvase>` 태그의 사용법

1. HTML에 `<canvas>` 태그로 영역을 지정하고 자바스크립트로 해당 캔버스를 선택해 그림을 그린다
2. 예시

	```html
	<canvas id="myCanvas" width="500" height="300"></canvas>
	```

	1. HTML 코드작성
	2. myCanvas라는 id를 부여
		1. 자바스크립트에서 이 캔버스를 찾기 위해
	3. 그림을 그릴 도화지의 크기를 width와 height로 지정

	```javascript
	const canvas = document.getElementById('myCanvas');
	
	// 드로잉을 위한 2D 렌더링 컨텍스트를 가져옴
	const ctx = canvas.getContext('2d');
	
	// 이제 ctx 객체를 사용해 그림을 그림
	ctx.fillStyle = 'red'; // 채우기 색상을 빨간색으로 지정
	ctx.fillRect(10, 10, 150, 100); // (10, 10)위치에 150X100 크기의 사각형을 그림
	```

3. `<canvas>` 태그를 이용해 그림을 그릴 때 자주 사용하는 자바스크립트 함수

	| 대표 함수                           | 의미                          |
	| ------------------------------- | --------------------------- |
	| getContext(’2d’)                | 캔버스에서 2D 그래픽을 그리기 위한 핵심 시작점 |
	| clearRect(x, y, width, height)  | 캔버스의 특정 영역을 지움              |
	| save() / restore()              | 현재 캔버스 상태를 저장/복원            |
	| fillRect(x, y, width, height)   | 채워진 사각형을 그림                 |
	| strokeRect(x, y, width, height) | 테두리만 있는 사각형                 |
	| beginPath()                     | 새로운 경로(Path) 시작             |
	| drawImage(image, x, y)          | 이미지를 캔버스에 그림                |
